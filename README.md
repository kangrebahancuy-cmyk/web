# Growtopia Website

This project contains the static HTML landing page for Growtopia, reorganized for local hosting.

## Run locally

```bash
python -m http.server 5500
```

Then open:

```text
http://localhost:5500
```

## Folder structure

```text
.
├── index.html
├── README.md
├── .gitignore
├── assets/
│   ├── css/
│   ├── js/
│   ├── fonts/
│   ├── images/
│   └── vendors/
├── components/
└── pages/
```

The original HTTrack mirror artifacts were removed from the public root and the live page was restored as the root `index.html`.
